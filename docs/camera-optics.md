# Photometric camera optics

Install `optics::CameraOpticsPlugin` and add `CameraOptics` to an HDR perspective camera. The plugin meters actual scene-linear luminance, applies bounded photographic exposure and a conservative small-angle scattering PSF before tone mapping. `OpticsReadback` opts into actual GPU diagnostics; normal cameras allocate no readback buffer. Full-target perspective views and scatter footprints up to 32 pixels are supported.

The reflected meter is `EV100=log2(8 L)` for cd/m², corresponding to ISO100 and Sekonic K=12.5 ([manufacturer](https://sekonic.com/faqs/)). Scene pre-exposure is read from `ExtractedCamera` and divided out. The generated spot-meter policy uses a 64² sample grid over the central half of the sensor, a 256-bin log2 histogram over [-20,40], and the geometric mean of percentiles 75–95. A central 4x4 pixel arithmetic spot bounds the meter from below, preventing a resolved source directly under the aim from falling between histogram samples. Positive compensation reduces EV. Defaults bound targets to [-6,20]; adaptation uses `delta*(1-exp(-dt/1s))`, capped at 1 stop/s brightening or 4 stops/s darkening, dt≤0.1s. Manual mode applies immediately. These meter selection and response choices are generated camera policy, not a measured human eye.

The PSF is `(1-a)delta + a exp(-theta²/(2 sigma²))/(2 pi sigma²)`, a=0.01, sigma=0.1 degree by default. This small-angle, shift-invariant approximation is motivated by optical scatter: [Tan et al. 2017, DOI10.7498/aps.66.044201](https://wulixb.iphy.ac.cn/en/article/cstr/32037.14.aps.66.044201) derive a Gaussian focal-plane illumination model from Harvey BSDF. Our parameters are not measured lens data. Discrete separable kernels truncate at ceil(4 sigma), normalize, and reflect image boundaries. RGB energy is redistributed rather than added, with no brightness threshold. Offscreen sources, spectral aberrations, aperture diffraction and ghosts require a lens/extended-sensor model absent here. The conservation claim applies below the sensor-storage saturation ceiling to linear RGB before tone mapping and learned processing. The final exposed value clamps to65000 before half-float storage so a night-to-day transition saturates instead of producing infinity.

External display effects can be ordered in `CameraOpticsSystems::ExternalDisplayEffects`. Solarik caches tone-mapped physical background first, then restores guide-free background after the external pass. Reverse-Z zero plus a conservative two-pixel neighbourhood determines absent geometry; mixed reconstructed silhouettes remain with geometry. No geometry-guided learned effect should invent or dim catalogue background flux merely because no depth guide exists. Surface pixels retain the external effect. This does not constrain learned opaque-surface radiometry. The full-image external pass still executes.

`OpticsReadback` supplies twelve f32 values: adapted EV, target EV, metered cd/m², valid count, GPU automatic flag, manual EV, input centre HDR luminance, pre-exposure, and output centre RGBA. Readback polling is nonblocking and opt-in; use a fresh destination for camera transitions to reject previous callbacks. GPU tests run with `--ignored --test-threads=1`: `camera_optics` checks production WGSL metering, f64 adaptation agreement, manual override, uniform fields and centre/edge flux conservation; `background_radiometry` checks sky preservation and surface passthrough. CPU tests cover calibration, bounds and normalized kernels.

The spherical atmosphere's visible Sun now uses the supplied angular radius and `L=E/(pi sin²(radius))` before air/cloud attenuation; `sun_angular_radius` defaults to the existing solar reference. Smooth pixel edge coverage is a resolved-disk approximation. No photospheric limb darkening is implied.
