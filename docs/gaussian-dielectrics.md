# Gaussian dielectric surfaces

`GaussianDielectric::new(ior, rms_slope, mask)` accepts IOR 1..7/3 and total RMS slope .025..1. The IOR ceiling follows the deferred UNORM8 reflectance encoding; larger values would silently disagree with ray shading. Mask alpha selects optics; RGB may retain a normal map. Attach `GaussianMaterial` for raster and register the same extension in `GaussianRayMaterials` for its `RaytracingMaterial3d` proxy. The caller owns entry lifetime. `SurfaceDetail` accepts identical parameters/mask; register both ray maps. Solarik deferred lighting uses the model; Bevy forward lighting retains GGX. Clearcoat is unavailable on these materials.

The Gaussian NDF and correlated Smith masking follow [Heitz 2014](https://jcgt.org/published/0003/02/03/paper.pdf), including the equation 69 Lambda approximation. Alpha squared is total slope variance. The shader returns the single-scatter BRDF times incoming cosine. GGX VNDF remains a full-support importance proposal with its own PDF. It is not the evaluated distribution. No Gaussian multiple-scattering compensation is provided.

Fresnel uses the exact air-to-dielectric unpolarized equations in [PBRT4](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission). Bevy's scalar reflectance r encodes sqrt(F0)=.4r, giving eta=(1+.4r)/(1-.4r). The gbuffer quantizes reflectance, perceptual roughness and coverage to 8 bits. Deferred flag bit3 assigns props.a to Gaussian coverage. Filtered boundary texels blend parameters and distributions as an effective surface, not exact areal transport. Diffuse attenuation uses smooth-interface transmission as an approximation.

`cargo test --test gaussian -- --include-ignored --test-threads=1` reads production WGSL results back from Vulkan: Fresnel, NDF normalization, slope second moment and reciprocity. Serialize with all builds and captures. Existing foliage/view-facing fixtures include the same library with Gaussian weight zero, preserving their original cases.

Direct-light visibility moves the numerical ray origin along the normal by max(1 mm, 8 epsilon_f32 max(abs(position))). This makes the outward displacement representable for camera-relative rigid geometry at orbital distances. It does not move the shading point. The production `ray_offset` GPU test checks displacement through 10 Mm; close-camera geometry retains millimetric offsets. This is an empirical floating-point allowance, not a complete triangle/transform error proof. Arbitrarily scaled or sheared geometry needs the full error propagation described by [NVIDIA](https://developer.nvidia.com/blog/solving-self-intersection-artifacts-in-directx-raytracing/). The native matched grazing fixture rejects self-shadow teeth; mesh refinement alone did not fix them.

## Native depth evidence

`DepthProbePlugin` is an opt-in, single-view fixture facility. Add COPY_SRC to the camera depth texture usage and disable MSAA. `DepthProbe.ticket` labels the requested state; an asynchronous `DepthRow` returns the centre scanline and dimensions. The WebGPU copy covers the full depth subresource, then retains only that row. One copy may be pending at a time. The fixture must wait for the matching ticket before using the data. Production applications should not install this debug plugin: full-resolution staging copies cost bandwidth. Geometric silhouette checks can then use actual positive reversed-Z depth instead of mistaking dark reflected radiance for missing geometry.
